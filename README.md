# ParaClass_App

## Para Athletics Classification App

This application is focused on enabling the general public to understand what are the different classifications within the Para sport means (what disability each classification represents) and how each classification is unique. It Educates people about the Paralympic classifications and promotes inclusivity and awareness.

---

## 🌟 Features

- **Comprehensive Classification Guide**: Detailed information on all Paralympic classifications.
- **Interactive Learning**: Quizzes and activities to test users' knowledge.
- **Athlete Stories**: Inspirational stories of Paralympic athletes.
- **Resources & Links**: Access to official Paralympic resources and further reading materials.
- **User-Friendly Design**: High-contrast mode, readable fonts, and accessibility features.
- **Real-Time Updates**: Live Paralympic news, event updates, and athlete insights.

---

## 📌 App Structure

### 🏠 Home Screen
- Welcome message
- Navigation to different sections (Classifications, Sports, Paralympic History, etc.)

### 🏅 Classifications Section
- Overview of disability classifications
- Detailed explanations of each classification

### 🎽 Sports Section
- List of Paralympic sports
- Rules and classification requirements per sport

### 🌟 Athlete Stories
- Inspiring accounts of Paralympic athletes
- Achievements and backgrounds

### 🧠 Quiz/Interactive Section
- Knowledge-testing quizzes on classifications and sports
- Interactive activities related to the classification process

### 🔗 Resources and Links
- Official Paralympic websites
- Educational materials
